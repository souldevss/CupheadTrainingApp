## King Dice death tracking

- Fixed a single King Dice death being recorded again when the timer resets and the game moves between minibosses and the board.
- Death tracking now waits for a new attempt to progress before accepting another death. Manual retries and miniboss victories remain excluded from death counts.
- Existing duplicate death entries can be removed from the boss attempt log.

## Windows compatibility notice

- This release remains unsigned. As described in the README warning, Windows SmartScreen or Smart App Control may block the app, including after earlier versions worked.

Validation: nine tracker regression checks passed, covering duplicate deaths, consecutive real deaths, retries, miniboss wins, final clears, and excluded equipment. Release build completed without warnings or errors.
