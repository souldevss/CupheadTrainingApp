## A simpler, more consistent interface

- Reorganized navigation: Training, Attempt Log, Time Table, Backups, and How it Works. Categories sit above the page tabs, and Check for updates is at the top left.
- Removed Run Projection, Run Recap, and the old palette controls. Added a simple light/dark switch beside the hand-drawn language flags.
- Bundled Cuphead Vogue and refreshed the interface with solid borders, offset shadows, and a softer blue, purple, and yellow light mode.
- Consolidated shared CSS and removed obsolete overrides. How it Works now has clearly separated section boxes in both modes.

## Boss logs and graphs

- Paper boss cards have larger text and boss-colored name boxes. A fixed icon sidebar on the left switches bosses and opens Overall Progress.
- Recent and individual boss attempts use the same compact grid, showing 20 entries before Load more.
- Clear all records moved to Recent attempts, with additional confirmation and a backup option before deletion.
- Graphs have thicker clear-time lines, subtle attempt points, a separate death-rate line, and animated smoothing and navigation. Animation stops when the graph settles.
- Fixed Overall Progress applying percentage normalization twice and showing extreme improvement values.
- Combined boss averages into one compact, centered table for the latest 10, 20, 50, 100, and 200 clears, plus Total. Only complete averages appear, and their times use rank colors. Best clear and playtime have separate accents.

Training can compare your PB or the average of a chosen number of recent clears. Tracking history and backup locations stay the same.

The app is still unsigned, so Windows SmartScreen or Smart App Control may block it. See the README for details.
