## Attempt Log
- Replaced boss cards with original Cuphead card artwork and local boss portraits, with clears, deaths, and playtime in a compact layout.
- Added a colored, icon-only boss sidebar. Hover to see names and use its first icon to open Overall Progress.
- Moved All bosses to the left of the view controls and Clear all records to a trash icon on the right. Clearing history now requires confirmation and typing DELETE (APAGAR in Portuguese).
- Recent attempts and individual boss attempts share the same compact card grid and Load more controls. Both start at 20 records and reveal another 20 on request, including deaths. Recent history can now be browsed beyond the previous 60-record limit.
- Added the supplied textured frame to boss graphs and adjusted the controls, labels, and shading to match it.
- Fixed horizontal overflow caused by navigation hover labels.

## Performance and cleanup
- Palette changes tint the small repeating background tile once, replacing a full-window GPU filter. Background drift uses fewer updates and pauses during scrolling.
- Reused unchanged graphs and cards, rendered boss attempt lists only when opened, and reduced SVG filter layers and overlapping markers in dense graphs. All clear times remain available for lines and hover.
- Batched graph hover work to animation frames and stopped live-point work while hidden. Brief focus changes no longer immediately trigger WebView memory trimming.
- Removed unused JavaScript helpers, obsolete styles, and an unreferenced repository screenshot.
